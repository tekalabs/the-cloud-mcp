# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting first:
select **Report a vulnerability** on this repository's **Security** tab.
If you cannot use that channel, email
[team@thecloud.so](mailto:team@thecloud.so).

**Do not open a public GitHub issue, discussion or pull request for a
vulnerability.** Public reports put users at risk before a fix ships.

Please include:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the affected version or commit,
- how you would like to be credited, if at all.

## What to expect

- We acknowledge your report and keep you informed as we investigate and fix.
- We follow a **90-day coordinated disclosure** window: please give us 90
  days from your report to ship a fix before you disclose publicly. If a fix
  ships sooner, we will agree a disclosure date with you. If we need more
  time, we will tell you why and ask before the window closes.
- We credit reporters in the release notes unless you ask us not to.

## Scope

This policy covers the code in this repository. Issues in The Cloud service
itself (thecloud.so and mcp.thecloud.so) can be reported to the same address.
