# Security Policy

Report vulnerabilities by email to [security@thecloud.so](mailto:security@thecloud.so). This is the security address for this repository because no security address was already present in the repository or its configuration.

Do not open a public issue for a suspected vulnerability. Include the affected component, reproduction steps, impact, and any suggested mitigation in the private report.

The public MCP layer and Claude Desktop bridge in this repository are in scope. The private backend is out of scope for this repository.
